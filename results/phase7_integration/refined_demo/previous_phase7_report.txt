# Phase 7: Integration and final project review

## Objective
Adapt an existing photograph to a user-directed cultural context while preserving its scene and protected objects. This review covers the current implementation and one bounded real ramen demonstration. **Project status: PARTIALLY COMPLETE. No culturally verified end-to-end transformation has been produced.**

## Architecture

```text
AUTOMATED: image -> SmolVLM -> Qwen raw draft -> deterministic validator
           REVIEW / ABSTAIN -> stop
           PROPOSE -> pending edit-intent review -> accepted grounding test
           -> all source-object boxes -> box-review boundary

GUIDED RESEARCH (independent objective, never a recovered Qwen candidate):
           source + explicit research specification -> Grounding DINO
           -> inspect/select pinned box -> SAM -> inspect/select pinned mask
           -> protected-sample veto -> SD inpainting -> original-size composite
           -> independent saved-pixel verification
```

The guided path is deliberately separate: a research objective is operator-specified and labeled RESEARCH_ONLY. It cannot accept planner candidates, review records or human-approval fields. It never changes the automated validator or its quarantined candidates. A named reviewer is not inferred from an assistant selection.

## Implementation

- `cli.py`: one configuration-driven `run --input` entry point; existing caption/plan/ground commands remain available.
- `orchestration.py`: existing real caption/planning, reviewed grounding and read-only replay remain unchanged.
- `guided_research.py`: thin progressive coordinator reusing existing detector, segmenter, inpainting and evidence readers. Missing explicit selections stop before the next model; it never chooses the highest score. A fresh output directory is mandatory for each invocation.
- Existing SAM contracts check source/detection/point hashes, original coordinates, binary masks and exact dimensions. All candidates are retained.
- Existing inpainting checks the pinned SAM candidate, crop/padding and mask hashes. It uses CPU offloading, one allowed OOM fallback and original-mask hard compositing.
- The coordinator independently reopens saved final pixels and rejects changed outside-mask pixels or a no-change result. Optional original-coordinate protected sample points veto a mask before diffusion. Passing these sparse checks does **not** establish full semantic preservation.
- No model checkpoint, prompt, thresholds, generation defaults, planner policy, schema or human-review authorization was changed in this completion. No new dependency or review framework was added.

## Evaluation and failure analysis

- **System correctness:** all requested stage handoffs are available through two explicitly separate modes; automated rejection/review boundaries remain intact. Explicit box and mask indices/hashes prevent implicit score selection. The real protected-pixel preflight stopped safely.
- **Preservation:** all original images and historical evidence are unchanged. A binary composite can guarantee outside-mask preservation but cannot protect ceramic accidentally included inside a bad mask. The experiment therefore did not generate. No complete semantic boundary verification or human mask approval exists.
- **Cultural relevance:** user-directed ramen-to-masala-noodles is the intended research objective. Qwen's text is a draft, not proof of cultural appropriateness. No generated ramen result exists for assessing culinary appearance, realism, lighting or seams.
- **Root cause:** the planner still lacks sufficiently specific edit scope; its generic uncertainty remains blocked. Independently, a text box around mixed food/utensils plus one fixed SAM refinement did not produce a safe food-only mask. New review infrastructure or validator relaxation would not repair those pixels.
- **No cherry-picking:** one Qwen call, one detection call and two SAM calls are retained, including unsafe/high-score masks. No further correction or generation attempt was made.

## Reproducibility

From the extracted package/repository root, use Python 3.11 and the installed versions in `environment.json`. Install this source with `python -m pip install -e ".[inpainting]"`; obtain a compatible CUDA PyTorch build separately. Cached pinned models are required for offline real runs, and Ollama must provide the recorded digest. No dependencies were upgraded in this completion.

```powershell
$env:PYTHONPATH = (Resolve-Path src).Path
$env:HF_HUB_OFFLINE = "1"
python -B -m unittest discover -s tests -v
python -B -m transcreation.cli run --help
```

Exact executed CLI commands (request JSONs contain all inputs, assumptions and fixed settings):

These commands were actually executed, not just proposed. They refuse to overwrite their existing output directories. For a new independent replay, copy a request to a new JSON and change only `output_dir` to a fresh path; saved source/detection/segmentation/mask paths remain relative to the extracted root. Do not regenerate upstream evidence and silently reuse stale downstream hashes. The last request is deliberately unsafe and should stop without generation.

An independently inspected future mask can use the same generation handoff by supplying its genuine segmentation JSON/hash, explicit candidate index, PNG hash, selection note and the fixed research specification. ## Limitations and outstanding decisions

The practical next requirement is **an explicit food-content scope plus a reliable inspected food-only mask** excluding the ceramic bowl and utensils. Confirm which toppings may change and whether liquid held in the spoon is protected. Every prepared new human box/mask review remains PENDING. Historical MATERIAL_UNRESOLVED is preserved, not retrospectively cleared. Model confidence, sparse points and assistant inspection do not substitute for a real human review or pixel ground truth.

A research-only mask selection never certifies cultural appropriateness or gives an automated edit permission. A future genuinely approved automated SAM/inpainting chain still needs explicit editing authority; existing segmentation-test acceptance alone cannot provide it. Source-image redistribution/license evidence is not established here; copies are supplied for the requested private research review. No independent external backup is claimed. Final evidence omits model weights, caches, environments and credentials.
