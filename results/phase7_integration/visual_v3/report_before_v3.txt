# Culture-Aware Image Transcreation: integration review

## Objective and current status
Adapt a photograph to an explicitly requested cultural context while preserving the original scene and protected objects. **PROJECT STATUS: PARTIALLY COMPLETE.** All stages and separate execution routes work technically. One real, localized ramen research generation now exists, but it produced a text-like artifact rather than convincing masala noodles. It is not a successful cultural adaptation.

## Architecture and implemented components

```text
AUTOMATED: image -> SmolVLM caption -> Qwen draft -> deterministic validator
           REVIEW / ABSTAIN -> stop
           PROPOSE -> explicit edit-intent review -> reviewed grounding test
           -> box-review boundary (no automatic SAM or diffusion approval)

GUIDED RESEARCH: explicit operator objective -> source-object detection
                -> explicit research box -> SAM -> inspected mask
                -> source/mask/protection checks -> inpainting
                -> original-resolution hard composite -> independent verification

REFINED RESEARCH: original source + genuine SAM reference + manual polygons
                 + full protected-region exclusions -> separate refined-mask input
                 -> same inpainting implementation and pixel-verification tools
```

SmolVLM-500M captioning, local Qwen2.5-3B structured planning, deterministic quarantine, Grounding DINO Tiny, SAM ViT-Base, Stable Diffusion v1.5 Inpainting and the existing review utilities remain implemented. Models run sequentially on the 4 GB RTX 3050 Laptop GPU. Diffusion uses FP16 and CPU offloading.

PROPOSE is an unapproved draft. REVIEW and ABSTAIN do not release executable edits. A segmentation-test acceptance is not editing permission. Operator-defined RESEARCH_ONLY generation is distinct from an approved Qwen plan and cannot retrospectively approve a rejected candidate.

## Refined mask: method, scope and provenance

Origin: **RESEARCH_MASK_MANUALLY_REFINED / RESEARCH_ONLY**. The operator annotation was made by the assistant from the original photograph; no named human mask approval is claimed. Genuine box-only SAM candidate 1 is retained as geometric reference, not relabeled as the derived mask. No synthetic SAM result JSON was created.

The new mask traces a small, clearly identifiable noodle patch between the tan strips at left, dark strips above, pink/white topping at right and green garnish below. Small sauce gaps within that patch are included. The polygon stays inward from all uncertain topping boundaries. All ceramic, spoon including contents, chopsticks, egg, meat, seaweed, other identifiable toppings, table and background are outside the edit.

Original-coordinate editable polygon:

```text
(537,414), (552,407), (575,405), (602,404), (624,407), (641,414),
(642,433), (636,451), (621,459), (605,454), (584,451), (564,445), (549,433)
```

Protected polygons cover every region above y=400, below y=465, left of x=530 and right of x=650, plus conservative explicit pink-topping and garnish exclusions. This protects the full surrounding regions rather than relying only on sampled points. These are deliberate broad conservative operator annotations, not independently labeled pixel ground truth. The editable mask is the rasterized editable polygon minus all protected polygons; the saved PNG must reconstruct exactly from the recorded geometry.

## Actual visual evaluation

**Generation feasibility: PASS. Cultural target appearance and visual quality: FAIL.**

The generated region contains an unwanted brown text-like, label-like graphic. It does not convincingly depict reddish-brown seasoned noodles. The patch interrupts noodle continuity and resembles an inserted label. A warm brown color alone is not evidence of Indian-style food or cultural correctness.

The ceramic bowl, spoon/contents, chopsticks, egg, meat, seaweed, other toppings and background are exactly preserved outside the small patch. Camera composition is unchanged. That numerical preservation does not make the inserted texture realistic. The full image is mostly unchanged by design; the close-up exposes the failure clearly.

This is a **PARTIAL LOCAL TRANSFORMATION ATTEMPT**, not an entire dish transformation. Only 4,224 pixels changed. No independently annotated total noodle area exists, so no noodle-coverage percentage, IoU, Dice or accuracy is reported. The cause of the text artifact is not established; the very small editable patch and narrow context may constrain generation, but that is a hypothesis, not a measured diagnosis.

The failed output and raw generated crop are retained unchanged. No second prompt, mask, seed, blending pass, text removal or manual image cleanup was attempted.

## Reproducibility

Python 3.11, tested Torch/Transformers/Diffusers versions are recorded in the preserved [environment metadata](../results/phase7_integration/final_demo/environment.json). No new dependency was added. Install this project with `python -m pip install -e ".[inpainting]"` into the compatible CUDA environment; pinned checkpoint weights must be locally cached for offline inference.

One command from the repository/extracted package root reproduces this exact research condition into a fresh directory:

```powershell
$env:PYTHONPATH = (Resolve-Path src).Path
$env:HF_HUB_OFFLINE = "1"
python -B -m scripts.inpaint --refined-input results/phase7_integration/refined_demo/input.json --out outputs/ramen_refined_reproduction
```

The JSON explicitly supplies original image/hash, original SAM reference/hash/index, refined mask/hash, protected mask/hash, annotation/hash and prompt. Existing output paths cannot be overwritten. Do not edit original SAM metadata to make the derived mask appear predicted. The condition remains RESEARCH_ONLY and is known to fail the requested visual appearance.

Without inference:

```powershell
python -B results/phase7_integration/refined_demo/verify_result.py
python -B -m unittest discover -s tests -v
```

A researcher can trace a different future geometry by explicitly updating polygon annotations and recording a new mask/protection/hash bundle, but no further variant was made here. Annotation rasterization is reproducible; its semantic correctness still requires visual judgment. Final review ZIP includes the exact geometry, source, reference evidence, masks, raw/final images, logs, code and configuration, with SHA-256 manifest and portable verification. No model weights, environments or caches are included.
