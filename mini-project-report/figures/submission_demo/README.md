# Supplementary guided full-scene image-transcreation demo

This folder contains a presentation illustration for the current submission. It is **not** a result of the project's validated automatic pipeline, is not part of Phase 9 evaluation, and must not be reported as evidence of automatic cultural transcreation.

## What it demonstrates

The comparison preserves the top-down food-stall framing, visible hands, light direction, fabric surface and general arrangement of the licensed source photograph while changing the food-display context to Japanese yatai-style elements (takoyaki, yakitori, onigiri and edamame). It is a guided AI image-editing illustration intended only to make the research concept easy to understand in a presentation.

## Files

- `source_indian_street_food.jpg` — the downloaded source image.
- `guided_japan_food_context.png` — AI-generated guided adaptation.
- `comparison_full_scene_guided_demo.jpg` — labelled side-by-side image for slides or the report appendix.
