\section{Safety and evidence contracts}
Every request binds image and mask hashes, source and replacement descriptions, edit scope and output directory. The validator can return \texttt{PROPOSE}, \texttt{REVIEW} or \texttt{ABSTAIN}; only appropriate, explicit review data permits continuation. The pilot's compositor additionally restores original pixels outside the permitted region after processing.

Let $I$ be the source image, $O$ the output, $M$ the permitted binary mask and $P$ a protected mask. Locality requires
\[
\forall x\notin M,\quad O(x)=I(x), \qquad \forall x\in P,\quad O(x)=I(x).
\]
These conditions prove containment of decoded RGB changes, not semantic or photographic quality.

\section{Reference-guided replacement}
For the final repeatability pilot, a frozen request selects a target reference, alpha selection, placement, shadow settings and a near-white reconstruction region. The compositor removes the source object in the approved region, places the aspect-preserved cutout and restores exterior pixels. This method is deterministic and CPU-only but depends on researcher-selected references and simple studio backgrounds.
